## Problem

Found by the review of `ticket-contract.explicit-ticket-marker` on 2026-11-19, and older than that change. A write that only appends a comment re-serializes the fence:

- CRLF line endings become LF
- the spaces before an inline comment collapse
- an untouched flow list `[a,b]` becomes `[a, b]`

AGENTS.md promises that a write never reformats what it did not touch (ADR 0003), and the write-fidelity test does not cover this case.

## Acceptance criteria

- [ ] A comment, a tick and a claim leave every untouched frontmatter line byte-identical, CRLF included
- [ ] A test through the harness pins each of the three cases above
- [ ] Where byte identity is impossible, the exception is stated in AGENTS.md beside the rule
