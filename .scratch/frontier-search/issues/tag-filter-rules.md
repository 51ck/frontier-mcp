## Question

The need is GitHub Issues-like filtering: `open` Tickets tagged `hotfix`. The Status half is specified in [[Tik4z0t]]. The tag half has no rules yet.

Agreed in conversation on 2026-11-18, as context: a Ticket may carry an optional `tags` list of arbitrary strings with no effect on Status or Edges. The key itself is part of the Ticket schema work under discussion around [[T79]] and is not built.

What is undecided, and deliberately not settled by this Ticket's filing:

- Several tags in one filter: any of them, all of them, or both forms
- Excluding a tag
- Case, and which characters a tag may hold
- Whether tags show on a Board line, given a Board is the token argument for the product
- How an agent learns which tags exist
- Whether Triage role remains a separate field
