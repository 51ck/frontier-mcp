## What to build

One call returns the Tickets that carry a given tag, alone or combined with the Status, kind and Triage role filters of [[Tik4z0t]], within one Effort or across all of them. The example that must work: open Tickets tagged `hotfix`.

Not startable yet. It waits on the rules in `tag-filter-rules`, on the cross-Effort narrowed read of [[Tik4z0t]], and on the Ticket schema gaining an optional `tags` list, which has no Ticket of its own yet and is under discussion around [[T79]]. Add that Edge when the schema Ticket exists.

## Acceptance criteria

- [ ] A Ticket's tags are read into the cached scan, so the filter reads no file
- [ ] The filter combines with the [[Tik4z0t]] filters as `tag-filter-rules` decided
- [ ] A filter that matches nothing returns a zero count, not an error
- [ ] A call without the filter is byte-identical to before
- [ ] The added schema cost is measured and recorded with the read-path measurements
