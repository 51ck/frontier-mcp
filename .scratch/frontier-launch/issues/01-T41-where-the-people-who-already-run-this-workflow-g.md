## Question

Which venues can actually put FrontierMCP in front of someone who already runs agent-driven ticket
workflows, and what does each one cost to enter?

Fact-finding only — no channel is chosen here. Produce an inventory. For each venue: what it is, how
big and how active, what a submission or post requires, whether it is moderated or curated, whether
self-promotion is welcome or punished, and what a realistic result looks like for an unknown project.

Cover at least:

- MCP server directories and registries — the official Model Context Protocol registry, `awesome-mcp-servers`-style
  lists, third-party marketplaces, and any Claude Code plugin or MCP marketplace that accepts submissions.
- The community around the Matt Pocock engineering skills — where its users actually talk, whether the
  skills repository accepts contributions or references to third-party tooling, and what the norms are.
- Agent-tooling communities: relevant subreddits, Discords, and forums where Claude Code / Cursor / MCP
  users discuss workflow tooling.
- Aggregators where a launch post is plausible: Hacker News (Show HN), Lobsters, dev.to, and equivalents.

Record dead ends explicitly — a venue that turns out to be inactive or hostile to self-promotion is a
useful finding, and stops a later session re-investigating it.

Use high-trust primary sources: the venues' own rules and submission docs, not blog posts about them.
